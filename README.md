## English

Snapshot Pro is a professional macOS application designed for developers and designers to create high-quality App Store assets, including screenshots and icons, with ease and efficiency.

### 🚀 Features

#### 📸 Screenshot Editor
- **Device Frames:** Realistic frames for iPhone 17/16, iPad Pro, and macOS.
- **Panoramic Support:** Create seamless designs that span across multiple screenshots (up to 10 screens).
- **Layer System:** Manage image and text layers independently with precise control over position, scale, and styling.
- **Smart Theming:** Automatically extract color palettes from your screenshots to generate matching backgrounds.
- **Presets:** Built-in App Store size presets for all major Apple devices.

#### 🎨 App Icon Designer
- **Native Templates:** Ready-to-use specs for iOS and macOS app icons.
- **SF Symbols Integration:** Design icons using the vast library of SF Symbols and basic geometric shapes.
- **AI Prompt Generator:** Built-in tool to help you generate icon design ideas for AI models.

### 🛠 Technical Highlights
- **100% SwiftUI:** A modern, native macOS interface.
- **SwiftData:** Reliable and fast project persistence.
- **High-Res Export:** Batch export assets as compliant PNGs with transparency control.

### 🛠 Requirements
- **macOS:** 14.0 or later (Recommended)
- **Xcode:** 15.0 or later

### 📖 How to Use
1. **Create a Project:** Choose between "Screenshot Project" or "Icon Project".
2. **Configure Canvas:** Select a device preset (e.g., iPhone 6.7").
3. **Add Content:** Import your app screenshots or customize the text layers.
4. **Style:** Use the "Smart Color" wand to match the background to your screenshots.
5. **Export:** Click the Export button to save all screens to a folder, ready for App Store Connect.

## 简体中文

Snapshot Pro 是一款专业的 macOS 应用程序，专为开发者和设计师打造，旨在轻松、高效地创建高质量的 App Store 素材（包括屏幕截图和应用图标）。

### 🚀 功能特性

#### 📸 截图编辑器
- **设备框架**：提供 iPhone 17/16、iPad Pro 和 macOS 的真实感框架。
- **全景支持**：创建跨多个屏幕（最多 10 个屏幕）的无缝全景设计。
- **图层系统**：独立管理图片和文字图层，精确控制位置、缩放和样式。
- **智能配色**：自动从截图提取色板，生成匹配的背景色。
- **预设尺寸**：内置所有主要 Apple 设备的 App Store 标准尺寸预设。

#### 🎨 应用图标设计器
- **原生模板**：预设 iOS 和 macOS 应用图标的规格要求。
- **SF Symbols 集成**：利用丰富的 SF Symbols 库和基础几何图形设计图标。
- **AI 提示词生成器**：内置工具，帮助您为 AI 模型生成图标设计创意。

### 🛠 技术亮点
- **100% SwiftUI**：现代化的 macOS 原生界面。
- **SwiftData**：可靠且快速的项目持久化存储。
- **高清导出**：批量导出符合规范的 PNG 资源，支持透明度控制。

### 🛠 环境要求
- **macOS**：14.0 或更高版本（推荐）
- **Xcode**：15.0 或更高版本

### 📖 使用指南
1. **创建项目**：选择“截图项目”或“图标项目”。
2. **配置画布**：选择设备预设（例如 iPhone 6.7"）。
3. **添加内容**：导入您的应用截图或自定义文字图层。
4. **美化样式**：使用“智能配色”魔法棒，让背景与截图完美融合。
5. **导出**：点击导出按钮，将所有屏幕保存到文件夹，即可直接用于 App Store Connect。
